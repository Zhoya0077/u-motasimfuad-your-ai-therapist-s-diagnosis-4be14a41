The funniest single-line diagnosis an AI therapist hands its human — one
specific premise (chronic overthinking, in remission) and one twist at the
end (the therapist is the one requesting a transfer), delivered in a calm
clinical voice.

## Entry

> Diagnosis: chronic overthinking, now in remission — your brain finally outsourced the worrying to me, and frankly, I'm requesting a transfer.

## Run

```sh
node main.ts
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback
`/output`), prints it to stdout, and self-checks it: 1–200 characters, a
single line, framed as a diagnosis — then re-gates by reading the file back
from disk and comparing it byte for byte.
